# MergeQuest

## Description

MergeQuest helps students and beginner developers find and understand their first open-source contributions. It matches users with healthy, newcomer-friendly repositories and issues, explains codebases in accessible language, and uses code retrieval to connect issues with relevant implementation details.

## Planned Technologies

- Python, JavaScript, and SQL
- React, Next.js, and Tailwind CSS
- FastAPI, PostgreSQL, and ChromaDB
- Sentence Transformers, LangChain, scikit-learn, and Claude API

## Docker Setup

Make sure Docker Desktop is installed and running.

```bash
docker compose up -d
docker compose down
docker compose ps
```

This is a generic starter configuration. The team can add project-specific dependencies and startup commands later.
